02 — How it works

Built for one crew, not the internet.

Identity is Sign in with Apple. Strava is just a data source. The board lives in CloudKit, filtered by invite code.

01

Sign in

Apple ID only. No extra account, no password to babysit after a long ride.

02

Join the crew

Enter a shared invite code. First person to use a new code creates the season.

03

Sync Strava

Each phone pulls its own swim, bike, and run. Teammates never share one API quota.

04

Log the beer

Tap plus, optional note, done. Recovery pints count toward the same Total Index.

03 — The board

Flip the sport. Keep the heat.

Overall, swim, bike, run, or beers. Same crew, different bragging rights. Sample names, real formula.
